# 📊 Survey Feedback Analyzer

## 🔹 Project Overview

This project analyzes customer feedback using Python. It performs text cleaning, word analysis, and generates useful insights from raw survey data.

## 🔹 Features

* Add new feedback entries
* Clean messy text data
* Count important words (good, poor, excellent)
* Calculate average rating
* Find longest feedback
* Extract unique words
* Sort feedbacks by rating

## 🔹 Technologies Used

* Python
* Core concepts: loops, functions, strings, dictionary

## 🔹 Sample Output

* Word count insights
* Average rating
* Cleaned feedback data

## 🔹 Learning Outcome

This project helped me understand text preprocessing and basic data analysis using Python.
